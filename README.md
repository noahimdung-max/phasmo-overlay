# 파스모 판별기 오버레이

파스모포비아를 하면서 게임 위에 띄워 두는 한국어 조사 노트예요. 비공식 팬 도구이고, Kinetic Games와 관련이 없어요.

## 내려받기

[Releases](https://github.com/noahimdung-max/phasmo-overlay/releases/latest)에서 `PhasmoOverlay-v1.1.0-win-x64.zip`을 받아 압축을 풀고 `PhasmoOverlay.exe`를 실행하세요.

- Windows 10/11 64비트. .NET을 따로 설치할 필요가 없어요.
- 게임 화면 모드를 **테두리 없는 창(Borderless Windowed)** 으로 해야 게임 위에 보여요.
- 폴더 안의 `fonts`, `reader`는 지우지 마세요.

## 기능

- **증거 판별**: 증거를 있음·없음으로 체크하면 30종 후보가 좁혀지고, 다음에 확인할 증거를 추천해요. 보장 증거는 ★로 표시해요.
- **타이머**: 헌트 진행·쿨타임, 향 차단 시간.
- **발소리 측정**: 발소리에 맞춰 탭하면 BPM과 속도를 보여줘요.
- **헌트 기록**: 최근 헌트 시간과 간격.
- **귀신 자동 판독**: 귀신 종류와 귀신방을 보여줘요(아래 주의 참고).
- **귀여운 유령 마스코트**: 클릭하거나 증거를 체크하면 반응해요. 설정에서 끌 수 있어요.
- **창**: 끌어서 이동·크기 조절, 스크롤, 투명도·크기 배율, 클릭 통과, 항상 위.

## 단축키 (설정에서 변경 가능)

| 동작 | 키 |
|---|---|
| 헌트 시작/종료 | F1 |
| 향 | F2 |
| 타이머 리셋 | F3 |
| 클릭 통과 | F4 |
| 표시/숨김 | F5 |
| 발소리 탭 | F6 |
| 증거 1~7 순환 | Ctrl+1~7 |
| 공개 증거 수 | Ctrl+0 |
| 계약 초기화 | Ctrl+F3 |

오버레이를 우클릭하면 설정과 정보 메뉴가 나와요.

## 귀신 자동 판독에 대해

- 함께 실행되는 `reader\ghostreader.exe`가 게임 메모리를 **읽기 전용**으로 읽어요. 값을 바꾸거나 게임에 코드를 넣지 않아요.
- **혼자 하기 용도**예요. 다른 사람과 하는 온라인 판에서는 쓰지 마세요.
- 설정에서 "오버레이와 함께 자동 판독 실행"을 끄면 사용하지 않아요.
- 게임이 업데이트되면 동작하지 않을 수 있어요. 기준 게임 버전은 v0.19.x예요.
- 다른 프로그램의 메모리를 읽기 때문에 백신이 의심 파일로 볼 수 있어요. 불안하면 이 기능을 끄세요.
